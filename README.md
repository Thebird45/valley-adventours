# Valley Adventours · Landing page

Excursión a la Reserva Natural San Cipriano desde Cali.

**Demo en vivo:** https://thebird45.github.io/valley-adventours/

## Diseño
Aventura: tipografía condensada grande, cortes en diagonal, slider de fotos con efecto Ken Burns y línea de tiempo del día.

## Detalles técnicos
- HTML, CSS y JavaScript puro: sin frameworks ni dependencias, un solo archivo.
- Totalmente responsive (escritorio, tablet y celular).
- Slider animado en CSS · línea de tiempo responsive · galería · preguntas frecuentes con <details> · botón flotante de WhatsApp.
- Botón de reserva directo a WhatsApp.

## Verlo localmente
Abre `index.html` en cualquier navegador.
